# 0.5.0-alpha.5 — Rust backend with conversation commands

First published pre-release of the Rust backend. Every backend operation now runs in a bundled Rust process, and this build adds conversation slash commands, a per-conversation OMP model editor, full tool archives and agent-specific conversation views. It is distributed as a GitHub pre-release; the stable npm `latest` channel remains **0.4.1**.

Requires DSH **0.2.2-rc.1** and Node.js **22+**. Bundled executables cover macOS arm64/x64 and Linux arm64/x64; the build for the running host is selected automatically, and other architectures are never executed.

## Rust backend

The plugin host is now a thin JavaScript shim in front of a Rust sidecar over bounded JSONL on stdio. Rust owns conversation/session storage, fleet and SSH/tmux handling, CLI discovery and configuration, provider event normalization, approvals, import, search/export and original OMP history; the Claude Node helper only invokes the official SDK and forwards its events and permission requests. No network listener and no automatic JavaScript backend fallback are added. Existing state files and the DSH/React interface are preserved.

## Conversation commands

Type `/` in a Claude Code, Codex or OMP conversation for searchable completion (Up/Down, Tab, Enter, Escape; Shift+Enter inserts a newline, and IME confirmation never submits). `/help`, `/status`, `/model`, `/effort`, `/permissions`, `/rename`, `/pin`, `/archive`, `/new`, `/stop` and `/export` run in Rust and never enter the provider's prompt or transcript. Failed commands keep their draft and request ID for an explicit retry; `/new` persists its receipt and fresh conversation in one atomic write. See the conversation commands section in `docs/unified-chat.md`.

## OMP model configuration

**Models** is now a tab in every OMP conversation rather than a separate sidebar page, scoped to that conversation's machine and workspace. It covers built-in and custom role assignments, project overrides, presets, provider connections and custom model definitions. Requires OMP 18.18.x for configuration management. See `docs/omp-model-configuration.md`.

## History, titles and views

- Full tool archives for new local and SSH turns: 16-call pages, search over complete inputs/results, UTF-8-safe paging of long values and JSONL export; older local OMP turns can recover their original session files.
- Automatic titles from the first prompt with manual rename protection and an explicit **Use automatic title** action.
- Agent-specific conversation tabs (Claude **Chat / Tools / To-dos**, Codex **Chat / Plan / Changes**, OMP **Chat / Tasks / Tools / Models**) with structured diffs, tool filters and OMP phased tasks, keeping the composer, drafts, approvals and stop control available.
- OMP semantic color accents that follow DSH's light and dark appearance.

## Validation and scope

`npm run check` builds the Rust binary and the JS bundle, then runs 192 passing plugin tests (two real-tmux lifecycle smoke tests are opt-in via `npm run test:smoke`) and 13 Rust unit tests. The suite covers protocol framing, all three providers, command parsing and lifecycle rules, stale settings revisions, approval interruption, `/new` retries after restart, tool-history paging/search, automatic titles and OMP model configuration. `npm run test:package` installs the actual tarball into an isolated directory and exercises its host routes, shipped client factory and a real backend subprocess; it passes for this build. CI verifies Linux and macOS on Node.js 22 and 24, and builds all four native executables from the same revision. Browser and provider behavior outside those fixtures is not covered by a live model run.

This remains a pre-release: attachments, rich interactive questions and cross-engine migration are not implemented, and the Rust migration is not a stable replacement for 0.4.1. Provider accounts still need usable authentication and quota.

## Install

The tarball attached to this release contains all four native executables. Install it through the plugin manager of the same DSH profile as your running GUI:

```sh
dsh plugin --profile web add /absolute/path/dsh-remote-agents-0.5.0-alpha.5.tgz
```

The npm dist-tag for this pre-release line is `next`; `latest` remains 0.4.1.

Use a separate test profile while evaluating the Rust backend, and restart the desktop application after installing. Do not install this pre-release into an unrelated `web` profile when using the desktop app. Existing conversations and workspace registrations are retained; the installed stable 0.4.1 release is not replaced unless you install this pre-release over it.

Verify the download against the attached `SHA256SUMS`.
