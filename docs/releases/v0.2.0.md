# v0.2.0 — Herdr 配置导入与多机 Agent 工作台

## 功能

- 在 DSH Web GUI 内统一管理本机和 SSH 机器上的 Codex、Claude Code、DSH TUI 与 Shell。
- 按项目组织 Agent，查看终端输出、发送输入、中断和停止；独立 tmux 会话支持断线保留。
- 导入 Herdr v0.9.5 格式的机器目录（catalog v1）与项目快照（session v3）：只读预览、明确确认、去重、原子写入和过期预览保护。
- 保留安全解析的 SSH 用户名/端口；项目导入必须明确指定目标机器。
- 内置 `herdr-import` Skill 与离线 CLI，插件启用后注册 Skill。

## 安装

下载 Release 附件中的插件安装包，通过对应 DSH profile 的插件管理入口安装。Web profile 可使用：

```sh
dsh plugin --profile web add /absolute/path/dsh-remote-agents-0.2.0.tgz
```

安装到当前 GUI 对应的 profile，并按宿主提示重新加载/重启及刷新。适配版本：DSH **0.2.2-rc.1**；运行主机需要 Node.js 22+，Agent 运行目标需要 macOS/Linux、tmux 和对应 CLI。SSH 认证使用现有 OpenSSH 配置，不存密码。

可使用附件 `SHA256SUMS` 校验下载包。

## 验证与边界

- 40 项测试通过，包含配置导入、安全校验、并发、DOM 交互、Skill 注册与真实隔离本机 tmux 生命周期测试。
- 尚未使用用户真实 Herdr 配置或 SSH 服务器进行联调，也未安装到用户当前 DSH GUI。
- 导入仅复制机器/项目配置，不接管、迁移或修改 Herdr 运行中的 Agent、会话、布局或历史。
- 当前为 MVP，不包含完整终端仿真、Git diff/worktree 操作或 Agent 语义状态识别。

详见仓库 README 和 Herdr 导入指南。
